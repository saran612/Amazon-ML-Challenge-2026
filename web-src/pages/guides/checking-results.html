Checking results

scripts/score.py is a standalone scorer. It uses only the Python standard library, so it runs anywhere and shares no code with the pipeline it checks.

python scripts/score.py --pred work/model/val_matching_results.tsv \
                        --truth work/model/val_ground_truth.tsv \
                        --source1 dataset/train/train_source1.tsv \
                        --per-entity per_entity.tsv

It prints macro F0.5, pair precision and pair recall. It also breaks the score down by singletons and non-singletons, by number of true matches (0, 1–2, 3–5, 6+), and by country when you pass --source1. --per-entity writes every S1 record's F0.5 together with its numbers of predicted and true matches, which makes it easy to sort and inspect the worst cases.

The scorer is forgiving about format but reports every problem it finds:

  • A missing S1 row is scored as an empty prediction.
  • Duplicate ids in a list are counted once.
  • Predicted S1 ids that are not in the ground truth are ignored.
  • A header that differs from source1_entity_id, matched_entity_ids is flagged.

Run python scripts/score.py --self-test to check the metric itself against the worked example.
