Unseen countries

The test files contain a country (France) that does not appear in the training data. The pipeline is designed so that such a country needs no configuration.

  • The model has no country feature.
  • Filler words, places, place links and name rarity are computed on the test files, so the new country gets its own statistics.
  • The new country gets the shared token map: the variants that all training countries agree on.

Measuring transfer with --proxy

--proxy simulates an unseen country with the training data. It trains two extra models, one on each of the two largest training countries, and scores each on the other country:

Direction First pipeline Current pipeline 0.901.00
Train on US → evaluate on India 0.925 0.934
Train on India → evaluate on US 0.963 0.976
first pipeline current pipeline For comparison, the same-country score is 0.986.

Most of the drop is in precision (wrong merges), and it is worst on businesses that have no match. --proxy therefore also searches for one stricter minimum match probability for unseen countries (0 to 0.98). It keeps that value only if it improves both directions on half B. No value has done so yet, so the rule is not applied. The proxy models skip the cross-encoder and consistency steps, and their encoder has seen pairs from both countries, so these numbers are approximate.
