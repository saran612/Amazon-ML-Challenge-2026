Working with a sample

Add --sample F to run on a fraction of the data: minutes instead of hours, while you develop or debug.

python scripts/train.py --sample 0.05
python scripts/test.py  --sample 0.05

The sample is chosen to keep the data consistent. For training, it keeps a random share of S1 businesses with all their matched records, plus the same share of distractors. For test files, which have no labels, it keeps the same share of each file. The sample is seeded, so repeated runs pick the same records.

Sample runs use separate folders (work/train_sample0.05/, work/model_sample0.05/, output/sample/), so they never overwrite a full model. test.py needs the same --sample value as the training run it follows.

A sample has fewer distractors per business than the full data, and less training data. Its scores are useful for comparing changes against each other, not for predicting the full-data score.
