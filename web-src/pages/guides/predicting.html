Running predictions

Apply a trained model to the test files.

python scripts/test.py

test.py looks for a finished model in work/model/, marked by model_id.txt. It reloads the configuration saved with the model, so the settings used in training also apply at prediction. You don't need to repeat training flags. It then:

  1. Normalizes the test files and applies the saved token maps.
  2. Recomputes filler words, places, place links and name rarity on the test files.
  3. Embeds the test names with the fine-tuned encoder saved in the model folder.
  4. Runs blocking and writes output/candidate_pairs.tsv.
  5. Scores every candidate, calibrates, and blends in the cross-encoder on the uncertain band.
  6. Applies the tuned decision and writes output/matching_results.tsv.

Before writing, it checks that every predicted match is also in the candidate set, and stops if one is not. It then logs a per-country summary: the number of S1 records, the share left empty, and the mean number of matches. This summary is a quick way to spot an unusual country. Prediction on the full test set takes about 2.8 hours.
