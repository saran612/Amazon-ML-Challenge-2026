Training a model

A full training run on the default configuration.

  1. Put the data in dataset/ (see Dataset format), and install with pip install -e ".[embed]".
  2. Run training: 
    python scripts/train.py
  3. Wait. On a 12-core, 24 GB laptop this takes about 3 hours. The first run also downloads the encoder. Progress is logged with timestamps, and every stage reports its duration and peak memory.
  4. Read the report printed at the end, or open work/model/train_report.json.

Training writes to two folders. work/train/ is the stage cache, and work/model/ holds the finished model (see Output files). The model folder is replaced only in the last stage, so a run interrupted before then leaves the previous model untouched.

What the report tells you

  • Blocking: pair recall overall, per pass and on hard slices; candidates per query; and the perfect-matcher ceiling.
  • Each configuration on half B: the blocking-score baseline, stage 1, stage 2 with a global threshold, stage 2 with expected F0.5, and with the cross-encoder or consistency step when they are enabled. Each shows macro F0.5, singleton F0.5, pair precision and recall, and the score by country.
  • Feature importance by group, and the top features.
  • Error analysis: false positives and false negatives by slice, and what fixing each slice would be worth.
  • The final choice: the decision parameters, cross-encoder weight, consistency setting and unseen-country rule that test.py will use.
