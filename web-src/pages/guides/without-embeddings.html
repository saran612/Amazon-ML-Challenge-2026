Without embeddings

With --no-embed, the pipeline runs on the core install. It needs no torch, no model download and no GPU.

python scripts/train.py --no-embed
python scripts/test.py

What changes:

  • Blocking pass D is skipped, so a name written in another script can only be found through its transliteration or its address.
  • The embedding cosine feature is set to −1, and the pass-D rank to 99.
  • The cross-encoder is switched off too, since it needs torch.

Expect the largest loss on non-Latin names, which are 7.2% of true matches. This setup is still the fastest way to try the pipeline, and it is what the end-to-end test and the synthetic quick start use.

Two related options keep embeddings but change the encoder. --no-finetune uses the pretrained weights as they are, and --embed-model NAME_OR_PATH uses a different encoder.
