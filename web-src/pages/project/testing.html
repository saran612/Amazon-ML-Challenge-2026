ruff check src scripts tests
Test file Covers
test_normalize.py Indic vowels survive transliteration; accents are folded; domain names; digits split from letters in addresses.
test_vocab.py The abbreviation test; token-map mining; the shared map keeps only variants all countries agree on; first house number.
test_features.py House-number distance; competitors among candidates with the same name.
test_decide.py Each record goes to its best S1 record; global threshold; expected F0.5 keeps the best prefix and returns an empty set for a likely singleton.
test_metrics.py, test_scorer.py The worked example, singletons and empty predictions, macro averaging, in both the pipeline metric and the standalone scorer.
test_pipeline_utils.py Query chunks never split a query; cache keys follow the settings.
test_e2e.py Trains and predicts on synthetic data without embeddings. Checks blocking recall > 0.9 and macro F0.5 > 0.7, one output row per S1 record, and that matches are a subset of the candidates.

GitHub Actions runs the unit tests and ruff on every push and pull request, using Python 3.11 on Ubuntu. The end-to-end test is not part of CI. Run it by hand after changing the pipeline. Ruff checks the E, F and W rule sets, with a line length of 130.

To test the embedding plumbing without torch, set ER_EMBED_BACKEND=hashing. This replaces the encoder with hashed character trigrams. It exists only for smoke tests, and real runs never set it.
