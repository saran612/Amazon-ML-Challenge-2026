Dataset

Download the dataset

The training and test files for Entity Resolver, as one zip file: about 1 GB to download and 2.5 GB once unpacked.

Download dataset

dataset.zip · 1.0 GB · hosted on Google Drive. If the download does not start, open the file in Google Drive.

After downloading

Unzip the file in the root of the repository. It creates the dataset/ folder, with train/ and test/ inside, which scripts/train.py and scripts/test.py read by default. Dataset format describes the files and their columns.
