Getting started

Dataset format

Put your data in dataset/, or anywhere else and pass --data-dir or set the ER_DATA_DIR environment variable. Only dataset/README.md is committed to the repository. Everything else in that folder is ignored by git.

dataset/
├── train/
│   ├── train_source1.tsv         # reference records (deduplicated)
│   ├── train_source2.tsv
│   ├── train_source3.tsv
│   └── train_ground_truth.tsv    # which S2/S3 records belong to each S1 record
└── test/
    ├── test_source1.tsv
    ├── test_source2.tsv
    └── test_source3.tsv

Source files

All six source files share one schema: tab-separated, with a header row.

Column Content
entity_id Unique id. The prefix names the source: S1-, S2- or S3-.
business_name Business name, in any script.
business_address Free-text address with comma-separated parts. Can be empty.
country Country label. Treated as an open set: a country can appear only in test/. 
entity_id       business_name         business_address                        country
S1-925783039    Orelee's Barbershop   1795 Westchester Drive, High Point, NC  US
S2-764573417    -- Holloway Peak Inc Seafood   105 ELM ST, MORGANTON, NC      US

Files are read with quoting turned off, because names contain quote characters. A field therefore cannot contain a tab or a line break. After reading, the loader checks the row count against the file's line count and stops with an error if they differ.

Ground truth

train_ground_truth.tsv has one row per training Source 1 record:

Column Content
source1_entity_id A Source 1 id.
matched_entity_ids Comma-separated Source 2/3 ids of the same business. Empty if it has no match. 
source1_entity_id   matched_entity_ids
S1-55344266         S2-249013014,S2-197070651,S3-478195123,S3-384364074

Each Source 2/3 record may appear in at most one row. Records that appear in no row are distractors: they belong to none of the reference businesses.
