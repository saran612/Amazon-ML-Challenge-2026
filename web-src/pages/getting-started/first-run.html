Getting started

Your first run

The real dataset is not included in the repository. A synthetic generator writes a small dataset with the same layout and the same kinds of noise, so you can try the whole pipeline in about a minute.

  1. Generatemake_synthetic.py writes a small training set and test set.
  2. Traintrain.py learns the model and prints a validation report.
  3. Predicttest.py writes the matches for the test set.

Generate synthetic data

python scripts/make_synthetic.py --out data_synthetic

The generator writes a train/ split with two countries (US, India) and a test/ split that adds a third country (France) that never appears in training. By default each country has 300 Source 1 businesses per split. In the generated data:

  • Each business has 0–6 records spread over Sources 2 and 3 (6% have none). Every record is a noisy variant: typos, swapped words, changed legal suffixes, domain-style names, abbreviated street types, reordered address parts, house numbers that are off by one or have a leading zero, and missing addresses.
  • About a quarter of businesses also get distractors. Some are unrelated businesses, and some are near-copies with an extra generic word and a shifted house number.

Train and predict

python scripts/train.py --data-dir data_synthetic --work-dir work_synthetic --no-embed --jobs 2
python scripts/test.py  --data-dir data_synthetic --work-dir work_synthetic --output-dir output_synthetic

--no-embed skips the neural encoder, so this works with the core install. --jobs 2 keeps the number of worker processes small. train.py writes the model to work_synthetic/model/. test.py loads it and writes its predictions to output_synthetic/.

Read the output

At the end, training prints a report measured on validation data that was never used for tuning. It covers blocking recall per pass, the macro F0.5 of each configuration, the score by country, feature importance, and an error breakdown. The same numbers are saved in work_synthetic/model/train_report.json.

Prediction writes two files. Both have one row per Source 1 business, in input order:

# output_synthetic/matching_results.tsv
source1_entity_id   matched_entity_ids
S1-…                S2-…,S3-…,S3-…
S1-…                                     # empty: no match found

# output_synthetic/candidate_pairs.tsv
source1_entity_id   candidate_entity_ids
S1-…                S2-…,S2-…,S3-…,S3-…,S3-…

To check the validation score yourself, run the standalone scorer on the validation files that training exports:

python scripts/score.py --pred  work_synthetic/model/val_matching_results.tsv \
                        --truth work_synthetic/model/val_ground_truth.tsv
