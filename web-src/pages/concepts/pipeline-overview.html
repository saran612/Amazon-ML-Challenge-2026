Core concepts

Pipeline at a glance

Six stages turn three input files into one set of matches per S1 record. Each stage has its own page under Pipeline.

scripts/train.py runs these stages in the order below. Each stage prints its timing and peak memory:

Training stage What happens
1/9 ingest + normalize Read the TSVs and the ground truth, then apply generic normalization.
2/9 learn vocabulary Mine token variants, then learn filler words, places, place links and name rarity.
3/9 multilingual name embeddings Fine-tune the encoder, then embed every distinct name.
4/9 blocking Find candidate pairs for each country and measure recall on validation.
5/9 features (training rows) Compute features for up to 30M training pairs, written to disk.
6/9 train matcher Train the stage-1 folds, then stage 2, and optionally the cross-encoder and proxy models.
7/9 score validation queries Stream features and scores for the held-out queries.
8/9 calibrate, tune, errors Fit calibration, tune the decision layer and every optional step on half A, then report on half B.
9/9 save model Write everything test.py needs to work/model/.

scripts/test.py repeats stages 1–4 on the test files, using the saved token maps. It then scores the candidates, applies the tuned decision, and writes the two output files.
