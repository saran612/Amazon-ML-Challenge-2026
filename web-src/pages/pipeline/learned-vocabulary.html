Pipeline

Learned vocabulary

Everything language-specific is learned from the data in er/vocab.py. One part is supervised and comes from training matches. The rest is unsupervised and is recomputed on whatever files are being processed.

Token variants Training matches (supervised) Loaded from token_maps.json
Filler words, places, place links, name rarity Frequency statistics Recomputed on the test files

Token variants

For each training country, the miner takes true pairs (up to 2M, all outside the validation set) and looks at the tokens that are left unmatched on both sides. When each side has at most four such tokens, every left–right combination is a candidate variant. A candidate is kept only if it passes three tests:

  • Support: it occurs in at least 25 pairs.
  • Confidence: it explains at least 30% of the rarer token's unmatched occurrences.
  • Similarity: the two tokens pass a test that works in any language. Either one is an in-order abbreviation of the other with the same first letter, or they have the same consonant skeleton, or their Jaro-Winkler similarity is at least 0.88. Tokens containing digits are never mapped.

Each token maps from the rarer spelling to the more frequent one, and chains are followed to their end. Examples it found: rd → road, c1inic → clinic, praivet → private, krnatk → karnataka. Names and addresses get separate maps.

A country that is not in the training data gets the shared map: only the variants that every training country agrees on.

Filler words

A name token that occurs in more than 1% of a country's names (llc, pvt, limited, services…) carries little information. These tokens are removed to form the core name. If that leaves nothing, the core name falls back to the full name. Blocking and most name features use the core name, and a few features still compare the full name.

Places and place links

An address segment without digits that recurs in a country, at least max(5, 0.002% of records) times, is a place. This splits each address into places and a street part, which are compared separately.

Places that often appear together in the same addresses are linked, for example a city with its département and its region (bordeaux | gironde, bordeaux | nouvelle aquitaine). Two addresses that name the same area at different levels then still agree. Links are learned per country, on up to 3M sampled addresses.

Name rarity

A common name is ambiguous, a rare one is almost an identifier. Two counts capture this:

  • core_cnt: how many S1 records in the country share this core name.
  • local_cnt: how many share it in the same place, keyed on the record's rarest place segment. A common name is only a problem if another business with that name is nearby.
