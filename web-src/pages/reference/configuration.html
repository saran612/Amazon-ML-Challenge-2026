Reference

Configuration

All tunable parameters are in one dataclass, Config in er/config.py. There is no configuration file. The command-line flags cover the common switches, and anything else can be changed by editing the defaults or by building a Config in Python.

from er.config import Config
from er.pipeline import run_train

cfg = Config(max_candidates=20, n_jobs=4)
run_train(data_dir, work_dir, cfg, sample=None, force=False)

The configuration is saved with the model in config.json, and test.py loads it from there. The tables below list the settings you are most likely to change.

Vocabulary

Setting Default Meaning
stop_df_ratio 0.01 A name token in more than this share of a country's names is a filler word.
place_min_ratio / place_min_count 2e-5 / 5 How often a digit-free address segment must recur to count as a place.
abbrev_min_support 25 Minimum number of pairs for a token variant.
abbrev_min_confidence 0.3 Minimum share of the rarer token's unmatched occurrences.
abbrev_max_pairs 2,000,000 Training pairs sampled for mining.

Blocking

Setting Default Meaning
topk_char / topk_addr / topk_joint / topk_embed 10 / 8 / 10 / 15 Candidates per pass (A, B, C, D).
max_candidates 16 Candidates kept per query by combined score.
keep_top_per_pass 3 Top hits of every pass kept regardless of the cap.
retrieval_max_df / retrieval_min_df_cap 0.01 / 200 Columns more frequent than this are ignored during retrieval.
char_ngram 3 Character n-gram size for pass A.
ann_nprobe 16 IVF lists probed in pass D.

Model

Setting Default Meaning
val_frac 0.05 Share of training S1 records held out (half A + half B).
max_train_pairs 30,000,000 Budget of candidate pairs for training LightGBM.
n_folds 3 Stage-1 folds, grouped by S1 record.
lgb_rounds / lgb_early_stop 2000 / 100 Boosting rounds and early-stopping patience.
lgb_params 255 leaves, lr 0.05 LightGBM parameters (see Two-stage LightGBM).
stage2_top_features 24 Base features passed on to stage 2.
sib_min_comb / sib_max_per_s 0.5 / 10 Definition of strong siblings.
feature_chunk 1,500,000 Pairs featurized per chunk. Lower it to reduce memory.
seed / n_jobs 2026 / 10 Random seed, worker processes.

Embeddings and cross-encoder

Setting Default Meaning
use_embeddings / finetune_embed True / True Switches behind --no-embed and --no-finetune.
embed_max_len / embed_batch 32 / 256 Encoder input length and inference batch size.
finetune_pairs / finetune_batch 300,000 / 128 Fine-tuning data and batch size.
finetune_lr / finetune_temperature 2e-5 / 0.05 Fine-tuning learning rate and contrastive temperature.
use_cross_encoder True Switch behind --no-cross-encoder.
ce_train_pairs / ce_max_len 300,000 / 96 Cross-encoder training pairs and input length.
ce_train_band / ce_band (0.02, 0.98) Score band used for training and for re-scoring.
ce_weight_grid 1.0, 0.75, 0.5, 0.25 LightGBM weights tried in the blend (1.0 = off).

Decision grids

Setting Values Meaning
t_assign_grid 0.02 … 0.3 Minimum probability for a record to be assigned.
miss_mass_grid 0, 0.1, 0.25, 0.5 Expected true matches that were never delivered.
global_t_grid 0.2 … 0.9 Global thresholds (step 0.025) tried for comparison.
consistency_lambda_grid / consistency_sim_grid 0 … 1 / 0.7, 0.85 Consistency strength (0 = off) and minimum similarity.
unseen_min_p_grid 0 … 0.98 Candidate minimum probabilities for unseen countries (--proxy).
