Module map

The package lives in src/er/. Each module covers one stage or concern.

Module Responsibility
pipeline.py The training and test runs end to end, the stage cache, tuning, and reports.
config.py The Config dataclass and default paths.
io.py Reading source and ground-truth TSVs; writing the id-list outputs.
normalize.py Transliteration, cleaning, domain detection, address segments.
vocab.py Token-variant mining, filler words, places, place links, name rarity, house numbers.
embed.py Encoder fine-tuning, name embedding, FAISS search (in isolated processes).
blocking.py The four retrieval passes, combined score and cap, blocking recall report.
features.py The 77 pair features, including siblings and competitors.
model.py Two-stage LightGBM, query context, calibration, model save and load.
crossenc.py Cross-encoder training, scoring and logit blending.
decide.py Owner assignment, expected-F0.5 set selection, global threshold.
consistency.py The optional anchor-based consistency step.
split.py Validation halves and consistent sampling.
metrics.py Macro F0.5 and its breakdowns.
analysis.py Error analysis by slice and error examples.
synthetic.py The synthetic dataset generator.
log.py Timestamped logging with stage timing and peak memory.
