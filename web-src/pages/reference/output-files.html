Reference

Output files

What each script writes, and where.

Predictions: output/

File Content
matching_results.tsv source1_entity_id, matched_entity_ids. One row per test S1 record in input order; comma-separated ids, empty when there is no match.
candidate_pairs.tsv source1_entity_id, candidate_entity_ids. Every candidate the model scored. Each row's matches are a subset of its candidates.

Model: work/model/

File Content
stage1_fold0..2.txt, stage2.txt LightGBM models.
stage2_cols.json, calibration.npz Stage-2 feature columns, isotonic calibration curve.
token_maps.json Mined token variants per country, plus the shared map *.
config.json, decision.json Full configuration; chosen decision parameters, cross-encoder weight, consistency setting, unseen-country rule and feature list.
embed_model/, embed_key.txt Fine-tuned encoder and its cache identity (with embeddings on).
ce_model/ Cross-encoder (only when it was chosen).
train_report.json Everything in the printed report, plus the configuration and training time.
val_matching_results.tsv, val_ground_truth.tsv Final predictions and truth for validation half B, in the official format, for score.py.
error_examples.tsv Up to 200 random false positives and 200 false negatives, with both records' names and addresses.
model_id.txt Written last. Marks a complete model and invalidates cached test scores.

Cache: work/train/ and work/test/

Normalized records (Parquet), embeddings (emb.npy), candidate pairs (pairs.parquet), the training feature matrix (X_train.npy, memory-mapped), and one <stage>.key file per stage (see Caching and resuming). You can delete these folders at any time. The work/ and output/ folders are ignored by git.
