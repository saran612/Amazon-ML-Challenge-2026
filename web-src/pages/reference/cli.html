Command line

Four scripts in scripts/ are the entry points. Each accepts --help.

train.py

Trains the full pipeline and writes the model to work/model/.

Option Default Effect
--data-dir PATH $ER_DATA_DIR or dataset/ Where the train/ folder is.
--work-dir PATH work/ Where the cache and model go.
--sample F off Use a consistent fraction of the data.
--force off Delete the cached stage outputs and start over.
--jobs N 10 Worker processes. LightGBM and FAISS use N + 2 threads.
--no-embed off Skip name embeddings (pass D, the embedding cosine) and the cross-encoder.
--no-finetune off Use the pretrained encoder without fine-tuning.
--embed-model NAME intfloat/multilingual-e5-small Encoder name on Hugging Face, or a local path.
--no-cross-encoder off Skip the cross-encoder re-scoring.
--no-consistency off Skip the consistency step.
--proxy off Also train and report leave-one-country-out models.
--sim-drop F 0 Share of non-validation S1 records to remove, to simulate a denser crowd.

test.py

Applies the trained model to test/ and writes the two output files.

Option Default Effect
--data-dir PATH $ER_DATA_DIR or dataset/ Where the test/ folder is.
--work-dir PATH work/ Must contain the model from train.py.
--output-dir PATH output/ Where the results go (output/sample/ for sample runs).
--sample F off Use the sample model and a data subset. Must match the training run.
--force off Ignore cached test-stage outputs.
--jobs N as trained Worker processes.

score.py

Scores any prediction file against any labelled file.

Option Effect
--pred FILE Predictions: source1_entity_id ⇥ matched_entity_ids. Required.
--truth FILE Ground truth in the same format. Required.
--source1 FILE A Source 1 file. Adds a breakdown by country.
--per-entity FILE Write each S1 record's F0.5 and its numbers of predicted and true matches.
--self-test Check the metric on the worked example (0.714) and exit.

make_synthetic.py

Writes a synthetic dataset in the expected layout.

Option Default Effect
--out PATH required Output folder. train/ and test/ are created inside it.
--n-s1 N 300 S1 businesses per country and split.
--seed N 0 Random seed.
